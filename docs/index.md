# Kosh

Kosh allows codes to store, query, and share data through an easy-to-use Python API. Kosh lies on top of Sina and can use any database backend supported by Sina.

Kosh provides consistent access to data through loaders, transformers, and operators, decoupling data access from data format and location.

## Getting started

Install the latest public version:

```bash
pip install kosh
```

For development from a cloned repository:

```bash
pip install .
```

For more details, see the [installation doc](https://github.com/LLNL/kosh/blob/develop/INSTALL.md).
